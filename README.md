# ロゴ作成ツール

シンプルで使いやすいWebベースのロゴ作成ツールです。HTMLキャンバスを使用して、ブラウザ上でロゴをデザインできます。

## 機能

### テキスト編集
- テキストの入力と編集
- フォントサイズの調整（12px〜120px）
- 7種類のフォントから選択可能
- テキスト色の変更
- ドラッグ&ドロップでテキストを移動
- X/Y位置の細かい調整

### 背景設定
- 背景色のカスタマイズ
- 透明背景のサポート

### 図形追加
- 円の追加
- 四角形の追加
- 図形の色をカスタマイズ
- ドラッグ&ドロップで図形を移動

### エクスポート
- PNG形式でダウンロード
- キャンバスのクリア機能

## 使い方

1. ブラウザで `index.html` を開きます
2. 左側のサイドバーでテキストや図形を編集します
3. キャンバス上のテキストや図形はドラッグして移動できます
4. 完成したら「PNGとしてダウンロード」ボタンでロゴを保存します

## ファイル構成

```
├── index.html  # メインHTMLファイル

```

- HTML5 Canvas
- CSS3（グラデーション、フレックスボックス）
- Vanilla JavaScript（フレームワーク不要）

## ブラウザ対応

モダンブラウザ全般で動作します：
- Chrome
- Firefox
- Safari
- Edge

## 開発者向け

### ローカルサーバーで実行

```bash
# Python 3を使用
python -m http.server 8000

# Node.jsを使用
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセスしてください。
